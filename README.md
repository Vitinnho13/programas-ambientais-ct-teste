# Prévia estática — Programas Ambientais do CT

Esta versão é somente uma prévia pública do site. Ela não inclui o painel CMS, login, servidor/API dinâmica ou recursos de edição. O conteúdo é uma cópia estática capturada do conteúdo público disponível no servidor local; alterações feitas posteriormente no CMS não aparecem aqui automaticamente.

O GitHub Pages publica esta prévia em:

https://vitinnho13.github.io/programas-ambientais-ct-teste/

Para refletir novas alterações, é necessário gerar e publicar uma nova cópia estática. Não envie o banco de dados, backups, arquivos privados, painel administrativo ou credenciais para este repositório.
